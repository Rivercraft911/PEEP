# PEEP
Have you been dreaming of keystroke injection but the existing devices are just too big and heavy? PEEP is a tiny, open-source, optically controlled USB HID automation device built around the STM32F042.

Open [`PCB/peep/peep.kicad_pro`](PCB/peep/peep.kicad_pro) in KiCad 10 for the hardware design.
